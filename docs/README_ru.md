# PS4 Commander

Двухпанельный файловый менеджер для PS4 в стиле Norton/Total Commander: payload с веб-интерфейсом. Откройте `http://<IP PS4>:8484/` в браузере любого устройства в вашей сети.

## Возможности
- Две панели, управление с клавиатуры (F-клавиши, Tab, Insert/Пробел, `+`/`-` отметка по маске, `*` инверсия) и сенсорные кнопки.
- Копирование, перенос, удаление, переименование, новая папка и файл, права (chmod), размер папки, с прогрессом и отменой.
- Просмотр текста и hex, предпросмотр картинок/аудио/видео, встроенный редактор текста (до 1 МБ).
- Скачивание папки (или нескольких объектов) ZIP-архивом, который собирается на лету без временных файлов (Ctrl+D).
- Сетевые папки по SMB (SMB2/3: Windows, Samba, NAS; в окне добавления можно найти серверы в локальной сети и показать их папки) отображаются как `/smb/<имя>`: просмотр, скачивание, копирование и перенос в обе стороны, ZIP, поиск. Добавить папку: клавиша `N`; пароли хранятся на консоли в `/data/ps4commander/smb.json`.
- Установка `.pkg` прямо из сетевой папки: установщик сначала пробует папку FUSE (монтируется в `/data/pkg`, а если ядро откажет - на флешке; без копирования; прошивка должна быть в таблице патча fusefs), а иначе делает временную копию, которая удаляется после установки. Какой способ сработал, видно в логе.
- Загрузка (кнопка или перетаскивание) и скачивание.
- Рекурсивный поиск файлов по маске.
- Установка `.pkg` штатным установщиком (BGFT) с очередью и прогрессом (Enter на `.pkg`).
- Безопасность: защита системных путей, явный режим «unsafe», защита от CSRF и DNS-rebinding.
- Языки интерфейса: английский, русский.
