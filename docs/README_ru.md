# PS4 Commander

Двухпанельный файловый менеджер для PS4 в стиле Norton/Total Commander: payload с веб-интерфейсом. Откройте `http://<IP PS4>:8484/` в браузере любого устройства в вашей сети.

## Возможности
- Две панели, управление с клавиатуры (F-клавиши, Tab, Insert/Пробел, `+`/`-` отметка по маске, `*` инверсия) и сенсорные кнопки.
- Копирование, перенос, удаление, переименование, новая папка и файл, права (chmod), размер папки, с прогрессом и отменой.
- Просмотр текста и hex, предпросмотр картинок/аудио/видео, встроенный редактор текста (до 1 МБ).
- Загрузка (кнопка или перетаскивание) и скачивание.
- Рекурсивный поиск файлов по маске.
- Безопасность: защита системных путей, явный режим «unsafe», защита от CSRF и DNS-rebinding.
- Языки интерфейса: английский, русский.
